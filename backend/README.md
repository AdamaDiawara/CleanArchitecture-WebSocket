## Startup

```shell
npm init -y
```

```shell
npm i -D typescript
```

```shell
npx tsc --init
```

- on décommente le outDir dans le tsconfig.json
- on ajoute dans scripts le build, dev et le start
- on va ensuite créer un fichier `index.ts`

```shell
npm run dev
```

## Lancement du projet

npm run dev
npm start

## Build

npm run build && npm run start
